# Nhat-Minh Le-Phan — academic homepage

Plain HTML + CSS, no build step. Inspired by the layout of fbullo.github.io.

## Publish on GitHub Pages
1. Create a public repo named **minhk43pbc.github.io** on GitHub.
2. Upload all files in this folder (Add file → Upload files) and commit.
3. Visit https://minhk43pbc.github.io (Settings → Pages if it doesn't appear after a minute).

## Edit
- Pages are plain HTML; edit text directly.
- Photo: photo.jpg
- Sidebar links are repeated in every page (inside `<aside id="sidebar">`); update all pages if you add one.
- Colors/fonts: top of `style.css`.
